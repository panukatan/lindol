# An Interface to the PHIVOLCS Earthquake Bulletins

The Philippine Institute of Volcanology and Seismology (PHIVOLCS)
maintains the National Earthquake Monitoring and Information which aims
to provide accurate and timely information on significant earthquakes
and tsunami events that may significantly impact the Philippines and
ensures the accessibility and integrity of earthquake data. This package
provides an interface to this dataset through the frequent earthquake
bulletins released by PHIVOLCS.
