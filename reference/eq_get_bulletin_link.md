# Get URLs for detailed PHIVOLCS earthquake information bulletins

Get URLs for detailed PHIVOLCS earthquake information bulletins

## Usage

``` r
eq_get_bulletin_link(.url)

eq_get_bulletin_links(.url)
```

## Arguments

- .url:

  Base URL or monthly URL for PHIVOLCS earthquake bulletins. This is
  usually produced through a call to
  [`eq_build_url()`](https://panukatan.io/lindol/reference/eq_build_url.md).

## Value

A character vector of URLs for detailed PHIVOLCS earthquake information
bulletins.
